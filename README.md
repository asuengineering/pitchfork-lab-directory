# pitchfork-lab-directory

A WordPress block plugin to create a directory of related lab sites for a typical school.

## Features

- Research Lab custom post type.
- Research Area taxonomy for filtering.
- ACF fields for external URL, recruiting status, and PI ASURITE ID.
- ACF-powered Research Lab Directory block with client-side search and filters.

The block renders all lab results server-side and progressively enhances the listing with a small plain JavaScript filter controller.
